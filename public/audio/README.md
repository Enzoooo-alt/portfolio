# Audio custom du portfolio

Ajoute ici tes fichiers audio (MP3 recommandé) avec ces noms exacts :

- `mario-galaxy-gusty-garden.mp3`
- `mario-64-bob-omb.mp3`
- `wii-sports-title.mp3`
- `tomodachi-life-theme.mp3`
- `inazuma-eleven-match.mp3`
- `yokai-watch-main-theme.mp3`

Le lecteur global utilise ces pistes dans tout le site.

## Important

- Utilise uniquement des fichiers que tu as le droit d'utiliser.
- La lecture auto peut être bloquée par le navigateur : clique sur `Play` dans le menu Wii pour démarrer.
